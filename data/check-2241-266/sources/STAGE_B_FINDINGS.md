Timing residual is observed minus predicted. Raw frequency residual uses the same convention. Centred frequency residual is observed minus predicted minus `MU_BFO`.

The primary timing criterion is an absolute residual no greater than 43 µs, inclusive, at both the full and half integration steps. Opposite classifications would be boundary-sensitive. The frequency diagnostic applies the same two-step rule at ±7 Hz and does not determine the timing label. The observed timing therefore gives an inclusive predicted-timing interval of 14,497 to 14,583 µs.

All values come from the exact canonical event file pinned before Stage A. No alternate observation, calibration, orbit or satellite input was tried. The release, event file, sealed predictions and comparison source are included in the packet.
