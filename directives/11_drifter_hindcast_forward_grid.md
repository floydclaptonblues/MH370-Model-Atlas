## Step E. Drifter hindcast: does the frozen transport carry things the right distance? (run first)

3. Run the frozen model (B0: same currents, daily NCEP wind, K = 10 m2/s, RK4 1.5 h, no explicit Stokes) from each drifter's observed position and time. For wind response use the class slip closest to a drifter's configuration, stating which and why; run C0-C3 slips as separate columns. Do not pick the best-scoring slip.
4. Horizons: 1, 3, 7, 14 days (the frozen criteria), plus 30, 60, 90, 180 days on drifters that live that long, where only the net-displacement metrics below apply. Re-initialisation from the observed track is allowed at stated intervals; chained free runs are reported separately from re-initialised ones.
5. Metrics per horizon, split by drogue status and by calibration/validation/holdout set: median and mean endpoint error (km); persistence endpoint error; skill vs persistence; **signed zonal displacement error (model minus observed, km, east positive) and ratio of modelled to observed net zonal displacement**; same for meridional; separation vs along-track decomposition; counts of drifters that ground or leave the forcing domain; counts excluded for forcing gaps. 6. Apply the frozen pass/fail table exactly. Output `drifter_validation_metrics.csv`, `drifter_validation_bias.csv`, `drifter_validation_pass_fail.csv`, `drifter_validation_bias.png` (signed zonal error vs horizon, with IQR).
