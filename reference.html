Reference map canonical data only

Every canonical dataset in this project on one map: ocean currents, surface winds, the satellite rings, the satellite’s own track, the last radar fix, the debris find record and the seabed search areas. Nothing modelled by this project appears here. Built because these datasets live in six different places and nobody publishes them together.

The map

 
Hover anywhere for position, current, wind and distance to the 7th arc.

View:
Currents are loaded one month at a time, about 0.8 MB each, so the first draw of a new month takes a moment. Vectors are thinned to roughly even pixel spacing as you change view; the underlying field is full resolution and the hover readout reads the grid cell, not the drawn arrow. The current grid ends at 14.8°N, so no arrows are drawn north of there.

Two cautions a first-time user needs. The debris coordinates are place-name geocodes drafted for this project and never independently verified, with a nominal 100 km radius — which is why each site is drawn as a circle. And the search boxes are rectangles: the real swaths are curved along the arc and narrower, so a point inside a box here was not necessarily searched.

Using the data directly

Every layer on this map reads a file in this repository. If the map is not what you need, the files are plain and documented:

FileFormat
data/events_canon.json19 rows, each tagged canonical_observation: timestamp, message type, observed frequency value, raw and corrected timing value, and inclusion flags
data/satstate.json11 rows: time, ECEF position x,y,z in km, velocity vx,vy,vz in km/s, subsatellite latitude and longitude
data/arc7.jsonlonlat: 200 [lon, lat] pairs, plus the published caption
data/rings.jsonTen rings: timestamp, timing value, angular radius in degrees, and the ring centre, with the derivation method and its checks in the header
data/finds.json21 sites, each with coordinates, place name and an item list carrying id, description, find date, region and leeway class
fields/index.json17 months: file name, label, snapshot date, first and last day covered
fields/YYYYMM.txtBase64 of four concatenated Int16 planes — mean u, mean v, snapshot u, snapshot v — each 345×225 on a 1/3° grid from 15.125°E, 59.875°S. Divide by 1000 for m/s; -32768 is land or missing
fields/winds.jsonlat, lon and 17 monthly entries with um, vm, us, vs in hundredths of m/s

The repository is floydclaptonblues/mh370-model-atlas. The field files are a subset prepared for this project; for full resolution or other variables, go to the originating services named above.

No part of this page locates the aircraft, and none of it is a result. It is the input material, assembled in one place because assembling it was the slowest part of starting this work. What this project did with it is in the closing report; how the models work is in Methods.
